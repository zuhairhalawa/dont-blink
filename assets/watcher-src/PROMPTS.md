# Watcher images: prompts

Generate these in any image tool (the Gemini app at gemini.google.com works on a free account). Save each image into this folder with the exact file name shown.

Tips:
- **Do image 1 first.** For images 2 to 6, stay in the same chat and start with "Same character as before, same costume and mask," so it stays the same creature.
- **Keep the background flat bright green.** The game cuts the green out. If a result has a shadow or a gradient on the background, ask it to "make the background a perfectly flat solid #00FF00 green with no shadow".
- **Full body for 1 to 5,** with the head and feet not cut off.
- **Use the largest size or quality option** the tool offers.
